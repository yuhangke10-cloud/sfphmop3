# Option3 v0.1.3

打开 index.html 预览。支持 Light/Dark 及 Line、Satellite、Network 三种地图按钮切换，主题切换保留地图选择。高度优先、水平居中。六张原始 7680×4320 PNG 无降质保存。

上传本文件夹内全部内容至 GitHub 仓库根目录，Pages 选择对应分支和 /(root)，无需构建。

素材映射：无后缀=Light Line，-1=Light Satellite，-2=Light Network，-3=Dark Line，-4=Dark Satellite，-5=Dark Network。

本版图片来源：Option3/4x。原始 line 对应 Line 按钮，net 对应中间按钮，map 对应右侧按钮；明暗模式分别匹配。
